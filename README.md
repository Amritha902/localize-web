# Localize — edit only what you mean

Web frontend for *Disentangling Localization from Editing in Instruction-Guided
Image Manipulation* (Amritha S, Yugeshwaran P; guide Dr. Saranya M, VIT Chennai).

Static site. The ten gallery demos are real outputs of the pipeline, stored in
`demos/`. Live runs call the inference backend (`api_server.py` in the main
project) whose URL is set in `config.js` or from "Backend settings" on the page.
