    How it works.

    Localization is separated from editing, so it can be measured on its own.

    1. 1

      Read the instruction

      “change the cat to a fox” → the object it acts on: cat.

    2. 2

      Find and outline it

      Grounding DINO finds the object; SAM 2.1 traces its exact boundary.

    3. 3

      Add what edits really touch

      Our trained head adds shadows and spill an outline misses, inside the detected boxes.

    4. 4

      Edit only there

      Any editor paints inside the region. Everything outside is copied back, pixel for pixel.

    Measured, not claimed.

    For each of 503 held-out MagicBrush edits we know the photograph before and after a human made the edit. The true edit region is every pixel that changed between the two (colour difference CIE76 ΔE above threshold). Each model predicts a region from the photograph and instruction alone, and is scored by IoU — the overlap with the true region divided by their union. 1.0 is a perfect match; none of these numbers come from the models' own reports.

    Why it matters.

    Not a rival to ChatGPT or Gemini — a layer any editor can use.

    Visible

    Closed editors decide where to paint internally and never show it. Localize shows the region before anything changes.

    Measurable

    A hidden region cannot be scored. Ours is scored directly against the ground truth — the base paper never reports this.

    Light

    Runs on a single laptop. The base paper needs a 20.43 B-parameter model on eight 80 GB GPUs.

    Preserving

    Without a region, an editor changed 93.1% of the pixels outside its target. With ours, 0.00%.

    The pixels are painted by an off-the-shelf editor (Stable Diffusion inpainting), so image quality is the editor's. A stronger editor can be dropped in without changing localization.
